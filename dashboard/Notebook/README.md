NHS National Cost Collection: Data Cleaning
This Google Colab notebook cleans and prepares the NHS England 2024/25 National Cost Collection (NCC) data for exploratory data analysis and dashboard development.

The project uses the NCCI by Department and Service, MFF unadjusted, 2024/25 dataset. The cleaned output is designed to support analysis of unit costs, actual and expected costs, activity, variance, and the National Cost Collection Index (NCCI) across NHS providers, departments, and services.
